# Goal
Mix related types of problem in a practice session, so that you practise choosing the method, and know when blocking one type at a time still makes sense.

# Why
In a textbook chapter, every exercise uses the method that chapter just taught, so you never have to decide which method to use. An exam mixes everything, and deciding is half the problem. Mixing your practice trains that decision. It feels slower and harder, which is why most people avoid it, and it's why the practice lessons in each 4YOS course mix topics on purpose.

# Lesson
## Blocked and mixed practice
**Blocked practice** means doing many problems of one type in a row: ten percentage questions, then ten ratio questions, then ten fraction questions. **Interleaved practice** means mixing the types in one session, so each problem could be any of them.

| | Blocked | Interleaved |
| --- | --- | --- |
| Order | AAAA BBBB CCCC | ABCA CBAC BACB |
| Feels | Smooth. Each one gets easier | Bumpy. Each one needs thought |
| Score during practice | Usually higher | Usually lower |
| Score on a later mixed test | Usually lower | Usually higher |

That last row is the important one. In Rohrer and Taylor's 2007 maths experiment, learners who practised blocked questions did better during practice, while learners who practised mixed questions did better on a test one week later. Practice scores can give a misleading impression of what will last.

## Why mixing works
When every problem in a row uses the same method, you only need to choose it once, then repeat it. You practise the steps, but not the decision. Interleaving forces you to look at each problem and ask: **what kind of problem is this, and which method fits?** That's the skill a real exam, or a real task at work, needs.

Mixing also makes you compare. Next to each other, a percentage question and a ratio question show their differences, and you start to notice the signals that tell them apart. Doing either kind on its own hides that difference.

It also brings in spacing. In a mixed set, the gap between two problems of the same type is longer, so each one is a small act of recall.

> Mistake: Judging a study method by how it feels during practice. Blocked practice feels better and scores higher in the moment. The test that counts is a later, mixed one.

## When to block, and when to mix
Mixing isn't always right. When a method is completely new to you, a short block helps you learn its steps first. Once you can do it with some help, start mixing.

| Stage | What to do |
| --- | --- |
| Meeting a method for the first time | A few problems of that type, in a block |
| Can do it, slowly | Mix it with the types you already know |
| Revising for an exam | Fully mixed sets, like the exam itself |

Mix things that could be confused, within one subject. Mixing statistics questions with each other helps, because you must decide between methods that look alike. Mixing one statistics question with one history question doesn't train any useful choice.

### How to make a mixed set
1. Gather problems from three or more topics you've already learned.
2. Shuffle them, or take them from different chapters in turn.
3. Before solving each one, write in a few words what type it is and which method you'll use.
4. Solve, then check. If you chose the wrong method, note what should have told you.

Step 3 is the heart of it. Naming the type before solving is the decision you're training.

Keep two scores as you go: how many times you chose the right method, and how many answers were right. They tell you different things. If your method choices are poor, you need more mixed practice and more attention to the signals in each question. If your choices are right but answers are wrong, you need practice with the steps of that method.

## Mixing at both schools
| Course situation | Mixed practice |
| --- | --- |
| A statistics module with five methods | Each session, take a few questions from every method so far |
| Maths revision | Use the mixed practice lessons, then past papers, which are already mixed |
| Programming | Write small programs that each need a different idea: a loop, then a decision, then a list |
| Security topics | Given a scenario, decide which threat and control fit before you look anything up |

Past questions are naturally interleaved, because an exam paper mixes topics. That's one more reason they're the best revision material you have.

=> Each problem makes you choose the method, which is harder. That choice is the skill a later mixed test needs.

# Practice
Use a subject where you know at least three methods or topics.

1. Gather 12 problems, about four from each of three topics.
2. Shuffle them.
3. For each problem, write the type and the method in a few words before you solve it.
4. Solve and check. Count how many times you chose the right method, separately from how many answers were right.
5. For every wrong choice, write what in the question should have told you.

Write your three topics, your method-choice score, your answer score and one signal you'll watch for next time.

# Rubric
- I mixed at least three related topics, shuffled.
- I named the type and method before solving each problem.
- I recorded how well I chose methods, and what signals I missed.

# Summary
- Blocked practice repeats one method. Interleaved practice mixes types.
- Mixing trains the decision: what kind of problem is this?
- It feels worse during practice and works better on later tests.
- Block briefly when a method is new, then mix.
- Mix things that could be confused, within one subject.
