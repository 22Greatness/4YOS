# Goal
Use sets and logical statements to describe a problem, then justify a conclusion with a proof or disprove it with a counterexample. The first available lesson covers set notation, operations, and counting overlapping groups.

# Units
## slp-sets :: Sets :: Represent groups and count overlapping membership.

# Project
The course project opens after the remaining units and assessment have been reviewed. Its brief asks you to specify and justify the rules for access to a shared resource.

# Project rubric
- The universe and membership rules are defined.
- The argument covers overlapping groups and explains any counterexample.
