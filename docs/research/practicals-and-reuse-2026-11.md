# 4YOS Camp academic benchmarks, work signals and repository review

Reviewed 7 November 2026. These sources inform outcomes, applied briefs and implementation patterns. Employer listings are dated examples of work and eligibility. The academic and release standard is in [master plan §22](../14-master-plan.md#22-4yos-camp-academic-and-global-readiness-standard).

## Global benchmarks and role evidence

MIT's Missing Semester instructors describe a specific gap they observed in the use of tools such as version control, editors and automation. MIT also documents hands-on undergraduate research through UROP. 4YOS Camp should teach the practical habits explicitly and offer research, lab and review workflows where learners can apply them. [Missing Semester](https://missing.csail.mit.edu/about/) · [MIT Undergraduate Research Opportunities Program](https://news.mit.edu/clp/undergraduate-research-opportunities-program-urop)

NACE's 2026 spring update reports that its surveyed employers generally find new graduates reasonably prepared, with room to improve. The World Economic Forum's 2025 employer survey identifies skills gaps as a barrier to business transformation, and the OECD's 2026 skills-first report examines how employers can assess demonstrated skills. Use these as evidence for assessed practice, work samples and feedback alongside the course outcomes. Keep employer surveys distinct from evidence about any particular university or discipline. [NACE employer findings](https://www.naceweb.org/career-readiness/trends-and-predictions/employers-say-new-grads-are-largely-prepared-for-work-with-room-to-improve) · [World Economic Forum Future of Jobs 2025](https://www.weforum.org/publications/the-future-of-jobs-report-2025/) · [OECD A Skills-First Labour Market](https://www.oecd.org/en/publications/a-skills-first-labour-market_2e1b85f0-en.html)

## What employers ask people to do

| Source and scope | What to teach and what to accept as evidence |
|---|---|
| [Byteworks developer internship](https://careers.byteworks.com.ng/jobs/HsifccXT_srs/software-developer-intern) lists Git and asks for examples of work. | Fix an issue in an unfamiliar repo. Submit the diff, a regression test, short commit history and README instructions another person can run. Progress from a Python script to an API with validation, migrations and error handling. |
| [Sabi Network data analyst](https://sabinetwork.com/job/data-analyst-4/) lists Excel skills. [Moniepoint metadata role](https://job-boards.greenhouse.io/moniepoint/jobs/5009923101) illustrates a later target with relational data, SQL and provenance, and lists a degree requirement. | Clean a messy register, reconcile totals against a control file, show which rows were excluded, reproduce the report with a SQL query and write a plain-language decision note. Later add tests, lineage and a repeatable refresh. |
| [Kora SOC analyst](https://apply.workable.com/koracareers/j/7DB41FE663/) describes monitoring, analysis and incident response. It is a role benchmark. | Triage a bounded synthetic log and packet capture, document timestamps and indicators, distinguish a false positive from a confirmed event, and hand over an incident note with evidence and next actions. Progress to an isolated detection and remediation exercise. |
| [Moniepoint careers](https://moniepoint.com/careers) shows distinct operations, engineering, risk and security tracks. [NBS labour force survey catalogue](https://microdata.nigerianstat.gov.ng/index.php/catalog/152) is the official source for wider labour indicators. | Teach two routes to experience. The first produces evidence for internships, junior roles and supervised work. The second produces a small deliverable a campus group or SME could use, with a scope, handover and privacy check. Keep the second route as portfolio practice until there is an actual client. |

For monthly research, collect first-party listings across software, data, cybersecurity and QA/support. Record observed date, employer, location or remote eligibility, experience, degree/NYSC requirements if stated, tools, actual work and link. Keep expired listings as dated skill evidence. Mark degree and location requirements separately from skill fit. Keep internships, ordinary employment and small client projects separate. Promote a tool to a core outcome only when several independent sources or the programme outcomes justify it. Preserve real application statuses and require the owner to approve the exact material before anything is sent.

## What to reuse

| Upstream | Decision | First proof before shipping or adopting |
|---|---|---|
| [System Design Primer](https://github.com/donnemartin/system-design-primer), [ByteByteGo System Design 101](https://github.com/ByteByteGoHq/system-design-101) | Architecture references. Use their prompts about load, failure and trade-offs to write original Nigerian briefs. These are strong matches for the architecture repo description. The exact shared URL is unconfirmed. | An original registration-system brief has measurable capacity and failure tests. Link to upstream reading. Check rights for each specific image, text or code asset before redistributing. |
| [RealWorld/Conduit example](https://github.com/gothinkster/react-mobx-realworld-example-app) | Clone-pattern reference for a shared API contract and independent implementations. Reuse the testing idea for a small stock or help-desk project. Avoid a stack migration. | An original API contract and fixtures run against the starter and a known-correct solution. Inject invalid auth, duplicate writes and pagination edge cases. |
| [Exercism canonical problem specifications](https://github.com/exercism/problem-specifications), [GitHub Classroom autograding](https://docs.github.com/en/education/manage-coursework-with-github-classroom/teach-with-github-classroom/use-autograding) | Use the exercise patterns: versioned cases, per-case feedback and repeatable checks. Keep the product workflow local and usable without a GitHub account. | Known-good solution passes. Empty code, a hardcoded sample answer, and a nearly correct solution each fail the right case. Use original briefs and fixtures. |
| [Pyodide](https://github.com/pyodide/pyodide) (MPL-2.0) and [sql.js](https://github.com/sql-js/sql.js/) (MIT) | Reuse the existing Python approach where it passes isolation checks. Trial a dedicated SQL lab database with sql.js only if the existing SQLite runtime cannot provide that isolation cleanly. Neither engine should share the learner records database with a lab. | Test bounded CPU/memory, Stop, restart from saved source, no unauthorized network access, and offline replay on the target phone. Measure runtime download bytes and cold start before choosing a second SQLite dependency. |
| [Playwright](https://github.com/microsoft/playwright), [Cloudflare Workers SDK / Miniflare](https://github.com/cloudflare/workers-sdk/tree/main/packages/miniflare) | Extend the existing Playwright checks to real user journeys. Use a local Workers runtime and D1 for integration tests. | A browser completes a real task, loses connectivity, restores its saved state and syncs after the server actually acknowledges it. Inject one D1 batch failure and verify no partial grant. |
| [Mermaid](https://github.com/mermaid-js/mermaid) (MIT), [k6](https://github.com/grafana/k6) (AGPL-3.0) | Optional architecture diagram rendering and instructor-side load testing. Start with a structured text/diagram artifact and a small load script. Keep k6 out of the learner bundle. | A queue or limiter lab compares the expected throughput and backpressure with a reproducible workload. Rendering untrusted diagrams must not introduce links or scripts into the app. |
| [OWASP Juice Shop](https://owasp.org/projects/juice-shop) (MIT) | Later supervised or local security lab. Start with static evidence files and a defensive investigation before taking on a vulnerable full application. | Prove that a learner can target only their own isolated lab. Reset removes the instance and credentials. No shared vulnerable endpoint or live-target assignment. |

Before adding a dependency, record the exact version, upstream license and asset notices, downloaded bytes, offline behaviour, maintenance owner, and an acceptance test. Repository licences do not automatically apply to every external diagram or dataset linked in a README. Record a permission and a source for each material the app ships.
